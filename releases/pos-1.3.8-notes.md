# SCCRMonPOS 1.3.8

- อนุญาตเครื่อง POS002 สาขา 004 (100.73.76.18) ที่ตรวจยืนยัน Tailscale และไฟล์ AdaPos แล้ว
- ผูกเครื่องนี้กับสาขา 004 / POS002 อัตโนมัติ และป้องกันการนำค่าจากเครื่องอื่นมาใช้เพื่อดึงบิลข้ามเครื่อง
- คงปุ่มกลับไปขายและตัวช่วยพักหน้าต่างเมื่อ SCCRM ค้างจากรุ่น 1.3.7 การอัปเดตยังให้พนักงานเลือกกดเอง

ใช้ตัวติดตั้ง 1.3.8 สำหรับการติดตั้งครั้งแรกบนเครื่องนี้ รุ่นเก่ายังไม่มีสิทธิ์ของเครื่อง POS002
การเพิ่มสิทธิ์ไม่เปลี่ยนข้อมูล AdaPos, Supabase, ประวัติซื้อ หรือโปรโมชั่นส่วนกลาง
บัญชี SQL อ่านอย่างเดียวและการเข้าสู่ระบบพนักงานยังต้องตั้งค่าตามปกติ

# SCCRM 1.3.25

- บันทึกประวัติใน SCCRM ก่อน แล้วตรวจและเติมข้อมูลบิลที่ขาดจาก Ada อัตโนมัติ
- ดูสถานะรอตรวจ เติมข้อมูลแล้ว หรือรายการที่ต้องตรวจสอบได้ที่เมนูเพิ่มเติม → สถานะซิงก์
- ตรวจซ้ำเป็นระยะ แม้บิลที่เคยตรวจครบแล้ว พร้อมเก็บ log ก่อน–หลัง
- ยังคงเจ้าของบิลเดิม และไม่สร้างบิลหรือแต้มซ้ำ

อัปเดตเฉพาะ SCCRM หลังบันทึกงานเสร็จ ไม่สั่งปิด AdaPos

# SCCRMonPOS 1.3.7

- หน้าสมาชิกและหน้าต่างย่อยไม่บังคับอยู่บนสุด จึงสลับกลับโปรแกรมขายได้เมื่อ SCCRM ไม่ตอบสนอง
- หน้าสมาชิกมีปุ่มบนแถบงาน ย่อและสลับกลับมาใช้งานได้สะดวก
- กล่องยืนยัน PIN อยู่กับหน้าสมาชิก ส่วน QR จอลูกค้าและขอบแสงสีน้ำเงิน–เหลืองยังใช้ได้ตามเดิม

การทดสอบใช้หน้าต่างจริงนอกจอและจำลอง UI ที่หยุดตอบสนอง เพื่อตรวจว่า
หน้าต่างอื่นวางเหนือ SCCRM และหน้าต่างย่อยได้ ไม่ได้หยุดหรือแก้โปรแกรม AdaPos
และไม่ได้เปลี่ยนฐานข้อมูลหรือข้อมูลสมาชิก

รุ่นนี้แก้พฤติกรรมบังหน้าจอ สาเหตุที่ SCCRM ค้างหรือ SQL ช้าเป็นช่วง ๆ
ยังต้องตรวจจากเครื่องที่เกิดอาการ การติดตั้งยังต้องให้พนักงานเลือกกดอัปเดต

# SCCRMonPOS 1.3.7

- หน้าสมาชิกยังอยู่บนสุดตามปกติ พร้อมปุ่ม SCCRM · กลับไปขาย ที่ทำงานแยกแม้หน้าสมาชิกค้าง
- หาก UI ค้างประมาณ 5 วินาที จะส่ง SCCRM ไปด้านหลังเอง และรอพนักงานเรียกกลับโดยไม่เด้งแทรกงานขาย
- พักหน้าสมัคร/แก้ไข/PIN แล้วเรียกกลับมาทำต่อได้ โดยเก็บข้อมูลที่กรอกไว้และใช้ QR จอลูกค้าได้ตามเดิม

การทดสอบใช้หน้าต่างจริงนอกจอและจำลอง UI ที่หยุดตอบสนอง เพื่อตรวจว่า
ปุ่มแยกและตัวตรวจ heartbeat ส่งกลุ่มหน้าต่างไปด้านหลังได้ทั้งตอนปกติและค้าง
รวมการพักและเรียกกล่อง modal พร้อมข้อมูลที่ยังไม่บันทึกกลับมา
ไม่ได้หยุดหรือแก้โปรแกรม AdaPos
และไม่ได้เปลี่ยนฐานข้อมูลหรือข้อมูลสมาชิก

รุ่นนี้แก้พฤติกรรมบังหน้าจอ สาเหตุที่ SCCRM ค้างหรือ SQL ช้าเป็นช่วง ๆ
ยังต้องตรวจจากเครื่องที่เกิดอาการ การติดตั้งยังต้องให้พนักงานเลือกกดอัปเดต

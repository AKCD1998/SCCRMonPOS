SCCRM POS Companion
==================

Use an approved company computer with AdaSoftware installed. Connect to the
company Tailscale network before installing or opening SCCRM, and keep it
connected while using SCCRM. Contact your administrator if access is refused.

1. Open SCCRM from the desktop shortcut or Start menu.
2. Sign in using the staff PIN configured by your administrator.
3. Press Ctrl+Alt+Q to open membership tools.
4. Choose staff registration or show the registration QR on a customer display.

Customer QR requires Windows to use Extend displays. The cashier can close it
using the blue/yellow button at the top center of the cashier screen.

Your administrator may recommend an updated release. SCCRM shows a notification;
you choose when to download, install and restart the membership companion.

Existing installation:
Close SCCRM before installing and select its existing folder. Setup backs up
configuration and merges the verified AdaPos settings, preserving unrelated
settings, private API credentials, the staff session, queues, and receipt history.
SCCRMonPOS.secrets.config and the data folder are retained when uninstalling.

New installation:
Setup reads existing SCCRM connection settings or the local StockDay sync agent's
read-only database identity. It discovers the current local SQL instance port,
checks read-only permissions and receipt tables, and enables the watcher before
installation completes. If no suitable settings exist, the connection dialog
asks the administrator for the AdaAcc read-only account. It never creates SQL
accounts or writes to AdaAcc. No production credentials are included in Setup.

The connection password is stored only in SCCRMonPOS.secrets.config on this
computer, with access restricted to the installing user, SYSTEM, and administrators.
Initial staff sign-in still uses your administrator's existing staff PIN.

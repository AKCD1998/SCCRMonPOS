# SCCRMonPOS 1.3.0

เพิ่มการตรวจสิทธิ์เครื่องบริษัทก่อนติดตั้ง ก่อนเปิดโปรแกรม และทุก 60 วินาทีระหว่างใช้งาน
เครื่องต้องอยู่ในรายการที่ตรวจรับรองไว้ เชื่อมต่อ Tailscale บัญชีบริษัท และมี AdaSoftware
ที่ติดตั้งอยู่ในเครื่อง หากตรวจสิทธิ์ไม่ได้ โปรแกรมจะปิดและให้ติดต่อแอดมิน

- ตัวติดตั้ง Windows แบบ .exe ใช้งานกับ Microsoft .NET Framework 4.8 ขึ้นไป
- ใช้โลโก้ SC และหน้าตัวติดตั้งของบริษัท รักษาไฟล์ตั้งค่าเดิมเมื่อติดตั้งทับ
- ตรวจ Tailscale Node ID, ชื่อเครื่อง, IP และไฟล์ AdaSoftware ในเครื่องร่วมกัน
- รุ่นนี้ปฏิเสธการอัปเดตไปยังรุ่นเก่าที่ไม่มีระบบตรวจสิทธิ์เครื่อง
- เครื่องใหม่ยังต้องกำหนด staff device/PIN และการเชื่อมต่อฐานข้อมูลหน้าร้านโดยแอดมิน
  ตัวติดตั้งไม่บรรจุรหัสผ่าน และปิดการเฝ้าดูฐานข้อมูล AdaPos ไว้เป็นค่าเริ่มต้น

รายชื่ออนุญาตเป็นรายการที่ฝังในรุ่นนี้ การเพิ่มหรือลดเครื่องต้องออกรุ่นใหม่
ตัวติดตั้งและโปรแกรม 1.2.0 เดิมยังไม่มีการตรวจนี้ การออกรุ่นใหม่ไม่ได้เพิกถอน
ไฟล์เก่าที่เคยดาวน์โหลดหรือสิทธิ์ backend เดิม

ทดสอบชุดตรวจ Desktop 34 รายการ, Member API แบบ offline 11 รายการ และสิทธิ์เครื่อง
18 รายการผ่าน พร้อมทดสอบปฏิเสธการติดตั้ง/เปิดบนเครื่องพัฒนาที่ไม่อนุญาตแล้ว
ยังไม่ได้ติดตั้งทดสอบบนเครื่องสาขาจริง

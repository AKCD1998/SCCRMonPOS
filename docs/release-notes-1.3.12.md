# SCCRMonPOS 1.3.12

- แสดงแต้มที่ Ada คำนวณในหน้าสมาชิกและประวัติซื้อ พร้อมบอกเมื่อยังอ่านยอดแต้มไม่ได้
- สแกนใบเสร็จแล้วบันทึกประวัติซื้อ โดยอ่านแต้มที่ Ada ให้ไว้และไม่แจกแต้มซ้ำ
- หากต้องการแต้ม ให้เลือกสมาชิกใน Ada ก่อนชำระเงิน; การสแกนบิลภายหลังไม่เพิ่มแต้มย้อนหลัง

เมื่อระบบกลางเปิดใช้แต้มจาก Ada ปุ่มยืนยันจะแสดง “บันทึกประวัติบิล”
และไม่คาดการณ์แต้มจากยอดเงินด้วยสูตรของ SCCRM อีกต่อไป
บิลที่ Ada ยังไม่มีรายการแต้มจะแสดงสถานะตามจริง แทนการแสดงว่าได้รับแต้มแล้ว

การอัปเดตแอปยังเลือกติดตั้งภายหลังได้ ค่าการเชื่อมต่อ สมาชิก และประวัติเดิม
ใช้ต่อได้ตามเดิม ออกจาก SCCRM ก่อนติดตั้ง โดยเปิดโปรแกรมขาย AdaPos ไว้ได้

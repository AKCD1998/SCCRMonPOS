# SCCRMonPOS 1.3.1

- บันทึกประวัติการซื้อของสมาชิกทั้งที่สมัครผ่าน QR และพนักงานสมัครให้
- แยกยอดชำระจริงจากยอดที่ใช้คิดแต้ม เก็บสินค้าในบิลครบ รวมรายการที่ไม่ร่วมแต้ม
- ยืนยันบิลที่ได้รับ 0 แต้มได้ เก็บลำดับสินค้า บาร์โค้ด ราคา ส่วนลด สาขา เครื่อง และผู้ขาย
- เปิดแท็บ **ประวัติการซื้อ** เลือกสมาชิก แล้วคลิกบิลเพื่อดูรายละเอียด
  ถ้ามีมากกว่า 100 บิล กด **โหลดบิลก่อนหน้า** ได้
- ป้องกันข้อมูลค้างเมื่อสลับสมาชิกและป้องกันยืนยันซ้ำหลังสำเร็จ

ต้องใช้ backend ที่มี migration `202610210002_purchase_history.sql` และ route
ประวัติที่รองรับ staff session แล้ว บิลเก่าที่ไม่เคยส่งยอดชำระจาก POS จะติด `*`
เป็นยอดรวมจากข้อมูลที่มี ไม่สามารถสร้างยอดชำระต้นฉบับย้อนหลังได้
แสดงเฉพาะบิลที่พนักงานเลือกสมาชิกและยืนยันใน SCCRMonPOS แล้ว

ยังแสดงและเก็บแต้มตามเดิม ไม่มีการรีเซ็ตแต้ม/ประวัติ และไม่มีการบังคับอัปเดต
คงการตรวจเครื่องบริษัทของรุ่น 1.3.0 ทุกจุด รวมถึงในตัวติดตั้งและระบบอัปเดต
ทดสอบ WinForms/API กับบิลจำลอง ไม่ได้ติดตั้งหรือยืนยันบิลบนเครื่องสาขาจริงในรอบนี้

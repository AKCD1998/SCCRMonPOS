# โปรโมชั่นแต้มส่วนกลาง

SCCRMonPOS 1.2.0 ใช้ Supabase/backend เดิมร่วมกับ 1.1.0 ไม่มีการบังคับอัปเดต
และไม่ดาวน์โหลดหรือติดตั้ง EXE เมื่อข้อมูลโปรโมชั่นเปลี่ยน

- เปิด “โปรโมชั่นสะสมแต้มส่วนกลาง” จากเมนู tray หรือเมนูเพิ่มเติมในหน้าสมาชิก
- หน้าบิล 1.2.0 อ่านตัวอย่างแต้มจากส่วนกลางทุก 30 วินาที ถ้าอ่านไม่ได้จะแสดง
  ว่ายังตรวจโปรไม่ได้ ส่วนการยืนยันต้องให้ backend คำนวณและบันทึกสำเร็จ
- รุ่น 1.1.0 ยังสะสมโปรเดียวกันได้โดยไม่เปลี่ยนไฟล์ แต่ตัวอย่างแต้มเก่าบนหน้า
  บิลใช้สูตรในเครื่อง ให้ดูโปรที่เว็บและอ้างอิงแต้มจากข้อความยืนยันสำเร็จ
- ทุกเวอร์ชันเปิดเว็บนี้ได้: https://sc-official-website.onrender.com/sccrm/promotions
  ใส่รหัสสาขาเพื่อดูโปรที่จำกัดสาขา ไม่ต้องล็อกอินสำหรับอ่าน
- ผู้ดูแลจัดการที่ `/sccrm/promotions/admin` ด้วยบัญชีเว็บที่ได้รับสิทธิ์
- อัตราฐาน 25 บาทต่อ 1 แต้ม ไม่รวมรายการชื่อขึ้นต้น “เภสัช” ตามกติกาเดิม
  โปรแต้มคูณ/โบนัสไม่เปลี่ยนส่วนลดที่ AdaPos คิดเงิน
- Backend ตรวจโปรปัจจุบันอีกครั้งตอนบันทึก และเก็บกติกาในประวัติบิลเดิมไว้
  การปิด/แก้ไขโปรจึงไม่เปลี่ยนแต้มที่เคยบันทึกแล้ว

`tools/PromotionCompatibilityCheck.csproj` โหลด ApiClient จาก EXE จริงแยก
process ต่อเวอร์ชัน รับ credential ทาง stdin เท่านั้น ใช้คู่กับสคริปต์
`backend/scripts/verify-promotion-compatibility.cjs` ใน repo backend เพื่อทดสอบ
รุ่น 1.1.0 เดิมกับ 1.2.0 โดยตรง รวม QR member, โปรคูณ 2, คูณ 3 + โบนัส 5,
ปิด/หมดอายุโปร, ป้องกันบิลซ้ำ และตรวจว่า hash ของทั้งสองไฟล์ไม่เปลี่ยน

การทดสอบนี้เรียก API จาก executable จริงกับข้อมูลจำลองที่จำกัดเฉพาะสาขาทดสอบ
ไม่ใช่การติดตั้งบนเครื่อง POS ระยะไกล และไม่อ่าน/เขียน AdaAcc

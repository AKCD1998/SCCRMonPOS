# ดูประวัติการซื้อสมาชิก

1. เปิด SCCRMonPOS และเข้าสู่ระบบพนักงานตามเดิม
2. โหลดบิลที่ชำระแล้ว ค้นหาสมาชิกด้วยเบอร์/ชื่อ/รหัส และตรวจชื่อก่อนเลือก
3. กด **ยืนยันบิล / สะสมแต้ม** รอข้อความ **บันทึกบิลสำเร็จ**
4. กดแท็บ **ประวัติการซื้อ** จะโหลดประวัติสมาชิกที่เลือกอยู่ หรือค้นหาสมาชิกใหม่
5. คลิกบิลเพื่อดูสินค้า จำนวน ราคา รหัส/บาร์โค้ด ส่วนลด และการคืนที่มีในระบบ
   เมื่อมีมากกว่า 100 บิล กด **โหลดบิลก่อนหน้า** จนหมด

สมาชิกที่สมัครจาก QR และที่พนักงานสมัครให้ใช้ประวัติชุดเดียวกันบน Supabase เดิม
ต้องมีการเลือกสมาชิกและยืนยันบิลใน SCCRMonPOS จึงจะรู้ว่าใครซื้อ ไม่ได้ผูกทุกบิล
ใน AdaPos ให้สมาชิกโดยอัตโนมัติ บิลที่ได้รับ 0 แต้มก็ยังบันทึกสินค้าได้
คะแนนยังเก็บและแสดงตามเดิม ไม่ได้ล้างคะแนนหรือประวัติของใคร

บิลรุ่น 1.3.1 เก็บยอดชำระจริงจาก GrandTotal แยกจากยอดที่ร่วมคิดแต้ม พร้อมข้อมูล
ที่อ่านจาก POS ส่วนบิลเก่าอาจมีเฉพาะยอดรวมจากรายการหรือยอดคิดแต้ม จึงติด `*`
และคำอธิบายเมื่อไม่มียอดชำระต้นฉบับ ห้ามอ้างว่าเรียกข้อมูลที่ไม่เคยบันทึกคืนมาได้

## ตรวจสอบสำหรับผู้พัฒนา

`tools/PurchaseHistoryCheck.csproj` มี 5 offline checks สำหรับบิล 0 แต้ม,
การส่งยอดชำระ/สินค้า และการปฏิเสธบิลคืน ใช้ร่วมกับ backend
`scripts/verify-purchase-history.cjs` เพื่อทดสอบปุ่มค้นหา/เลือก/ยืนยันจริงใน WinForms,
การโหลดรายละเอียดบิลแรก สลับสมาชิก ค้นหาไม่พบ โหลดหน้าถัดไป และเปิดใหม่อีก process
fixture ทั้งหมดเป็นข้อมูลจำลองและล้างออกหลังตรวจ ไม่มี AdaPos watcher ทำงาน

การตรวจนี้ใช้ component โดยไม่เรียก Program.Main จึงไม่ได้ทดสอบติดตั้ง/เปิดโปรแกรม
บนเครื่องสาขาจริง และไม่ได้เปลี่ยนหรือตัดระบบตรวจสิทธิ์เครื่องบริษัทที่มีอยู่
ก่อนใช้งานที่สาขายังต้องตั้งค่า staff device/PIN และการอ่าน AdaAcc ตามเดิม

# SCCRMonPOS 1.3.13

- อนุญาตเครื่อง FRONT2 สาขา 005 / POS 002 ที่ Tailscale IP 100.99.142.113 ให้ติดตั้งและใช้ SCCRM
- ผูกการอ่านบิลกับสาขา 005 เครื่อง 002 เพื่อไม่ดึงบิลของเครื่อง 001 หรือสาขาอื่น
- ใช้แต้มที่ Ada คำนวณตามรุ่น 1.3.12 และคงสิทธิ์เครื่องที่อนุญาตเดิมครบ

เครื่อง FRONT2 ต้องใช้ตัวติดตั้งรุ่นนี้ขึ้นไป รุ่น 1.3.12 และเก่ากว่ายังไม่มี
รายชื่ออนุญาตของเครื่องนี้ การอัปเดตยังต้องให้พนักงานเลือกกดติดตั้งเอง
ออกจาก SCCRM ก่อนติดตั้ง โดยเปิด AdaPos ไว้ได้ตามปกติ

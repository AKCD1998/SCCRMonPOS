# SCCRMonPOS 1.3.2

- ดาวน์โหลดไฟล์เดียว ติดตั้ง SCCRM พร้อมตั้งค่าเชื่อม AdaPos ในขั้นตอนเดียว
- ตรวจบัญชีอ่านอย่างเดียวและโครงสร้างบิลก่อนติดตั้งเสร็จ รองรับพอร์ต SQL Express ที่เปลี่ยนหลังเปิดเครื่อง
- สำรองค่าตั้งค่าเดิมและเก็บบัญชีพนักงาน สมาชิก คิวบิล และประวัติการซื้อไว้ตามเดิม

ตัวติดตั้งอ่านค่าจาก SCCRM เดิมหรือโปรแกรมส่งข้อมูล StockDay บนเครื่อง ถ้ายังไม่มี
ค่าที่ใช้ได้ จะให้ผู้ดูแลกรอกการเชื่อมต่อแบบอ่านอย่างเดียวก่อนดำเนินการต่อ
ไม่มีรหัสผ่านฐานข้อมูลรวมอยู่ในไฟล์ติดตั้ง และไม่สร้างบัญชีหรือแก้ไขข้อมูล AdaPos

ออกจาก SCCRM ก่อนติดตั้ง โดยเปิดโปรแกรมขาย AdaPos ไว้ได้ รุ่นนี้ยังตรวจสิทธิ์
เครื่องบริษัทและ Tailscale ตามเดิม และไม่มีการบังคับอัปเดตแอปเครื่องอื่น
การกดอัปเดตจากแจ้งเตือนจะเก็บค่าการเชื่อมต่อเดิม; การตั้งค่าครั้งแรกให้ใช้ Setup

# ระบบพรีออเดอร์ในหน้าประวัติการซื้อ

เลือกสมาชิกในหน้าประวัติการซื้อ แล้วกดปุ่มสีส้ม **ระบบพรีออเดอร์**

ตั้งแต่ 1.3.28 หากกดปุ่มก่อนเลือกสมาชิก จะมีข้อความ
**กรุณาพิมพ์ชื่อ/เบอร์โทรสมาชิกก่อน** กด **ตกลง** แล้วพิมพ์ในช่องค้นหาได้เลย

- **ข้อมูลประวัติพรีออเดอร์**: ดู เพิ่ม และแก้ข้อมูลที่พนักงานจดไว้ได้ ระบุสินค้า
  จำนวน หน่วย รอบซื้อ และที่มา วันที่ไม่ทราบให้เว้นไว้ได้
- **ข้อมูลบิลพรีออเดอร์จริง**: บิลที่สินค้าตรงจะอยู่ในส่วน **รอยืนยัน** พนักงานต้อง
  กด **ยืนยันว่าเป็นบิลพรีออเดอร์** ก่อน จึงขึ้นในรายการยืนยันแล้ว หากกดผิดให้ใส่
  เหตุผลแล้วกด **ยกเลิกการยืนยันบิลนี้** บิลขายจริงยังคงเดิม

หน้าต่างไม่ล็อกหน้าสมาชิกหรือหน้าประวัติ เปิดซ้ำจะกลับมาหน้าเดิม ไม่สร้างหน้าซ้ำ
การกลับไปขายจะเก็บหน้ากรอกไว้ หากยังกรอกข้อมูลอยู่ ตัวอัปเดตต้องรอให้บันทึก
หรือกดยกเลิกการแก้ไขก่อน ไม่ทิ้งข้อมูลและไม่ปิด AdaPos

ใช้ backend `/api/members/:id/preorders` โดยส่ง UUID สมาชิกเดิมและ staff token
ทุกครั้ง ตรวจ memberId ในผลตอบกลับ และใช้ requestId เดิมสำหรับการลองบันทึกซ้ำ
การเปลี่ยนสมาชิกที่หน้าประวัติไม่เปลี่ยนเจ้าของหน้ากรอกที่เปิดอยู่

ข้อมูลยืนยันบิลเป็นเพียงป้ายกำกับของบิลเดิม ไม่มีการสร้างบิล ซื้อสินค้า หรือให้แต้ม
เพิ่มจากหน้านี้ แต้มยังคงยึด Ada และรายละเอียด/หน่วยของบิลคงตามต้นทาง

`DesktopFeatureCheck` เพิ่มกรณีหน้าต่าง modeless, เปิดซ้ำ, เปลี่ยนสมาชิก,
เก็บข้อมูลเมื่อกลับไปขาย, กั้น updater ขณะมีหน้ากรอกซ่อนอยู่, ปิดเจ้าของ,
แหล่งข้อมูลกระดาษ, วันที่ไม่ทราบ และส่งหน่วย/หลายรหัสสินค้าเดิมครบ
ให้ใช้ Windows CI เดิมสำหรับ compile และ synthetic component checks ก่อนปล่อย
ไฟล์ตัวติดตั้ง ไม่อ้างว่าการอ่าน source ทดแทนการทดสอบ UI ได้

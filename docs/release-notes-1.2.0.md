เพิ่มโปรโมชั่นสะสมแต้มส่วนกลางจาก Supabase/backend เดิม

- เปิดรายการโปรผ่านเว็บจากเมนูโปรแกรมได้
- แสดงตัวอย่างแต้มจากเซิร์ฟเวอร์ในหน้าบิล และโหลดใหม่ทุก 30 วินาที
- ถ้าตรวจโปรไม่ได้จะแจ้งสถานะให้เห็น ยอดจริงต้องยืนยันจากเซิร์ฟเวอร์
- เครื่องที่ใช้ 1.1.0 ยังได้รับแต้มตามโปรเดียวกันได้ โดยไม่ต้องอัปเดตแอป
  รุ่นเดิมดูรายการโปรได้ที่เว็บ แต่ตัวอย่างแต้มบนหน้าบิลเก่ายังเป็นสูตรในเครื่อง
- การอัปเดตแอปยังเลือกภายหลังได้ ข้อมูลโปรโมชั่นแยกจากการปล่อย EXE
